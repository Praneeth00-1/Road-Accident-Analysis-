# Portfolio artefacts

This document packages the work so it can be presented as a complete analytics portfolio item.

## What to showcase
- A cleaned and documented accident dataset.
- SQL for schema definition and dashboard-oriented queries.
- Python scripts for automated data profiling and dashboard metric generation.
- A structured README, data dictionary and dashboard guide.

## Suggested portfolio story
"I built a reproducible end-to-end accident analysis workflow that turns raw road-accident data into actionable insight. The project covers data understanding, schema design, SQL-based query development, Python automation and stakeholder-friendly dashboard documentation."

- Highlight the analytical workflow rather than only the final charts.
- Emphasise that the repository is reproducible and easy to extend.
